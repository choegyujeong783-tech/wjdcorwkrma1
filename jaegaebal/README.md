# 광명재개발바로알기 — 홈페이지형 블로그

`jaegaebal/index.html` 한 파일로 동작하는 **홈페이지형 블로그 메인 페이지**입니다.
외부 라이브러리·폰트·이미지 의존성이 없어(로고까지 파일 안에 내장) 그대로 열거나
GitHub Pages에 올리면 바로 뜹니다.

> **제작 전제**
> 참고로 주신 네이버 블로그(`blog.naver.com/mapakc60`, 카테고리 13번)는 이 작업 환경의
> 네트워크 정책상 네이버 도메인 접속이 차단돼(HTTP 403) **본문을 직접 읽지 못했습니다.**
> 대신 유입 URL의 광고 파라미터(`n_query=광명11구역`, 파워링크 캠페인)와 공개 자료로
> **«광명뉴타운 재개발 매물·조합원 상담»** 성격의 블로그라고 판단하고, 그 독자가 가장
> 많이 묻는 순서(절차 → 숫자 → 권리 → 구역 → 체크리스트)로 구성했습니다.

## 1. 페이지 구성

| 영역 | id | 내용 |
|---|---|---|
| 타이틀 배너 | `#top` | 헤드라인 + **삼끝대책위 유튜브 바로가기** + CTA 2개 + 요약 지표 4개 |
| 위젯형 메뉴 | `#menu` | 8칸 아이콘 메뉴 (홈페이지형 블로그의 «메뉴바» 역할) |
| 재개발이란 | `#basic` | 재개발 vs 재건축 비교표, 사업의 돈 흐름 |
| 사업 절차 | `#steps` | 정비기본계획 → 청산까지 11단계 타임라인, 단계별 주의사항 |
| 분담금 계산 | `#money` | **비례율·권리가액·분담금·총투자금 실시간 계산기** |
| 조합원 권리 | `#rights` | 지위 양도 제한, 현금청산, 1+1, 이주비, 무허가, 세금 |
| 구역별 현황 | `#zones` | 단계 필터 + 진행률 바 (데이터 교체용 템플릿) |
| 체크리스트 | `#check` | 계약 전 12항목 + 확인 진행률 |
| 용어사전 | `#glossary` | 24개 용어 실시간 검색 |
| 최신 포스팅 | `#posts` | 블로그 글로 연결하는 카드 4개 |
| FAQ | `#faq` | 자주 받는 질문 6개 |
| 삼끝대책위 | `#daechaekwi` | 로고 + 채널 주소 + 유튜브 채널 바로가기 |

기능: 라이트/다크 모드 전환(선택값 `localStorage` 저장), 모바일 대응(좌우 스크롤 없음).

**상담 신청 폼은 넣지 않았습니다.** 개인정보를 수집하는 입력창이 한 곳도 없으므로
개인정보 처리방침·수집 동의 절차가 필요하지 않습니다. 방문자의 행동은
«삼끝대책위 유튜브 채널로 이동» 하나로 모입니다.

## 2. 유튜브 채널 주소 — 한 줄만 채우면 됩니다

`index.html` 하단 `<script>` 맨 위의 `CONFIG.YOUTUBE`입니다.

```js
var CONFIG = {
  YOUTUBE: '',   // ★ 삼끝대책위 유튜브 채널 주소
  TEL: ''        // 예: '010-1234-5678' → 푸터 연락처가 전화 링크가 됩니다
};
```

이 한 줄이 **6곳의 링크를 동시에** 바꿉니다.

1. 상단 고정 바의 «삼끝대책위» 버튼
2. 첫 화면의 «▶ 삼끝대책위 유튜브 바로가기» 버튼
3. 위젯 메뉴 8번째 칸 «삼끝대책위 유튜브»
4. 본문 대책위 블록의 «▶ 유튜브 채널 바로가기» 버튼
5. 푸터의 «유튜브 채널 방문하기»
6. 우측 하단에 떠 있는 «▶ 대책위 유튜브» 버튼

넣을 수 있는 주소 형태는 둘 다 가능합니다.

```
https://www.youtube.com/channel/UC0123456789abcdefghijkl
https://www.youtube.com/@삼끝대책위
```

**비워두면** 위 6개 링크는 유튜브에서 «삼끝대책위»를 검색하는 주소로 임시 연결되고,
대책위 블록의 주소 자리에 **«채널 주소 입력 필요»** 배지가 표시됩니다.
정확한 주소를 넣으면 배지가 사라지고 주소가 그대로 노출됩니다.

> 채널 주소 확인 방법 — 유튜브 채널 페이지 › «공유» › 채널 링크 복사,
> 또는 브라우저 주소창의 주소를 그대로 복사하면 됩니다.
> `UC`로 시작하는 24자리 문자열이 채널 고유 ID입니다.

### 그 밖에 채울 값

화면에 **«입력 필요»** 배지가 보이는 곳이 전부 교체 대상입니다.

- [ ] `CONFIG.YOUTUBE` — 삼끝대책위 유튜브 채널 주소
- [ ] `CONFIG.TEL`, 푸터의 대책위 연락처·소재지
- [ ] `#posts` 카드 4개의 `href`를 실제 블로그 글 주소로 교체
- [ ] `ZONES` 배열(구역 현황) — **현재는 예시 데이터이며 카드에 «예시» 배지가 표시됩니다**

```js
var ZONES = [
  { name:'광명 11R구역', stage:9, stageName:'이주·철거',
    households:'약 0,000세대', builder:'○○건설', note:'명도 지연 여부 확인', demo:false },
  // stage: 1~11 (본문 절차 단계 번호) / demo:false 로 바꾸면 «예시» 배지가 사라집니다
];
```

구역 정보는 반드시 **1차 자료**로 확인해 주세요 — 시·구 고시(공보), 조합 공고문,
정비사업 정보몽땅, 실거래가 공개시스템. 확인 안 된 값은 «확인 필요»로 남겨두는 편이
기자·독자 모두에게 안전합니다.

## 3. 네이버 블로그에 «홈페이지형»으로 얹는 방법

네이버 블로그 본문에는 임의의 HTML·JavaScript를 넣을 수 없습니다.
그래서 실무에서는 두 가지를 병행합니다.

### 방법 A — 블로그 자체를 홈페이지형으로 꾸미기

1. 이 페이지의 **타이틀 배너 + 위젯형 메뉴** 영역을 캡처해 이미지 한 장으로 만듭니다.
2. 블로그 **관리 › 꾸미기 설정 › 스킨 배경/타이틀**에 그 이미지를 등록합니다.
   - 권장 폭은 블로그 본문 폭과 같은 **966px**(네이버 기본 레이아웃 기준)입니다.
   - 규격은 네이버 정책에 따라 바뀔 수 있으니 등록 화면의 안내 수치를 우선하세요.
3. 메뉴 칸마다 **위젯**을 만들어 각 카테고리·글 주소, 그리고 유튜브 채널로 링크합니다.
   («관리 › 꾸미기 설정 › 레이아웃·위젯 설정 › 위젯 직접등록»)

```html
<!-- 위젯 직접등록 예시: 삼끝대책위 유튜브로 보내는 칸 -->
<a href="https://www.youtube.com/channel/UC…" target="_blank">
  <img src="이미지주소" width="170" alt="삼끝대책위 유튜브">
</a>
```

> 위젯은 폭이 좁으므로(기본 170px 계열) 메뉴 한 칸씩 잘라 넣고, 세로로 쌓아
> 배너 이미지의 메뉴 위치와 시각적으로 맞추는 방식이 일반적입니다.

### 방법 B — 이 HTML을 «랜딩 홈»으로 따로 운영 (권장)

계산기·체크리스트·용어검색처럼 **상호작용이 있는 기능은 블로그 안에서 불가능**합니다.
이 파일을 GitHub Pages 등에 올려 두고, 블로그 프로필·글 하단·위젯에서 링크하세요.

```
https://<사용자명>.github.io/<저장소명>/jaegaebal/
```

(저장소 Settings › Pages › Branch를 지정하면 자동 배포됩니다.)

### 방법 C — 모바일 확인

네이버 유입의 대부분은 모바일입니다. 등록 후 반드시 휴대폰에서
① 메뉴 링크가 눌리는지 ② 유튜브 버튼이 채널로 바로 열리는지 확인하세요.

## 4. 콘텐츠를 계속 쌓는 순서 (SEO)

홈페이지형 메인은 «입구»일 뿐이고, 검색 유입은 개별 글에서 나옵니다.
아래 순서로 글을 채우면 이 메인의 각 섹션과 1:1로 연결됩니다.

1. **구역명 + 단계** — 「○○구역 관리처분인가, 지금 무엇이 확정됐나」
2. **숫자 해설** — 「○○구역 비례율 ○○%, 내 분담금 계산해보기」
3. **주의 사례** — 「조합원 지위 승계 안 되는 물건, 이렇게 걸러냅니다」
4. **용어 1개당 1편** — 검색 롱테일(«권리가액이란», «현금청산 뜻»)
5. **월간 현황 정리** — 구역별 진행 상황 업데이트 (재방문 유도)

각 글 하단에 이 메인 페이지와 유튜브 채널 링크를, 메인의 `#posts` 카드에는 그 글 링크를
걸어 서로 순환하게 만드는 것이 핵심입니다.

## 5. 고지 사항

이 페이지의 본문은 **일반적인 정보 제공**이며 법률·세무·투자 자문이 아닙니다.
정비사업 관련 법령·조례·규제지역 지정은 수시로 바뀌고 구역별 적용도 다릅니다.
특히 아래 항목은 게시 전 최신 내용을 다시 확인하시기 바랍니다.

- 조합원 지위 양도 제한 요건과 예외 (규제지역 지정 현황에 따라 변동)
- 1+1 분양, 전매 제한 기간
- 취득세·양도세·종부세 관련 서술
- 세입자 보상(주거이전비·영업손실보상) 기준일
