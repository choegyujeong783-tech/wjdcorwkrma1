# 신청서 → 구글 메일(Gmail) 연동 방법

랜딩페이지(`경정청구.html`, `index.html`)의 신청 폼을 제출하면

1. **Gmail로 알림 메일**이 오고 (`choegyujeong783@gmail.com`)
2. **구글 시트에 한 줄씩 자동 저장**됩니다.

## 1. 구글 시트 + Apps Script 만들기 (5분)

1. 받을 구글 계정으로 로그인 → <https://sheets.new> 에서 새 시트 생성 (이름 예: `랜딩 신청서`)
2. 메뉴 **확장 프로그램 → Apps Script**
3. 기본 `Code.gs` 내용을 모두 지우고 이 폴더의 `Code.gs` 전체를 붙여넣기 → 저장(💾)
4. 위쪽 함수 선택에서 **`testSetup`** 선택 → **실행**
   - "권한 검토" → 본인 계정 선택 → "고급" → "(안전하지 않음)으로 이동" → **허용**
   - 메일함에 `[신규 신청] 테스트 …` 메일이 오고, 시트에 `신청서` 탭이 생기면 성공

## 2. 웹 앱으로 배포

1. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴 → **웹 앱**
2. 설정
   - 다음 사용자로 실행: **나**
   - 액세스 권한: **모든 사용자** ← 꼭 이것으로 (방문자가 로그인 없이 제출해야 함)
3. **배포** → 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`) 복사

## 3. 랜딩페이지에 URL 넣기

```bash
./apps-script/set-endpoint.sh "https://script.google.com/macros/s/새URL/exec"
```

`경정청구.html`과 `index.html`의 `CONFIG.ENDPOINT`가 한 번에 바뀝니다.
(직접 고치려면 파일에서 `ENDPOINT` 를 검색해 따옴표 안의 주소만 바꾸면 됩니다.)

## 참고

- **코드를 수정한 뒤**에는 배포 → 배포 관리 → 연필 → 버전 "새 버전" → 배포. (URL은 그대로 유지)
- 알림 메일 주소 변경: `Code.gs` 맨 위 `NOTIFY_EMAIL` 수정 (쉼표로 여러 명 가능)
- 무료 Gmail 계정은 Apps Script 메일 발송이 **하루 100통**까지입니다.
- 스팸 봇이 채우는 숨김 칸(`company_url`)이 채워진 제출은 저장·발송하지 않습니다.
