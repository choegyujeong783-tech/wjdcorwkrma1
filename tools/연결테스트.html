KBSS 접수 연결 테스트

Apps Script 웹 앱 주소가 신청폼과 제대로 연결되는지 확인합니다.

웹 앱 주소 입력

Apps Script에서 배포 → 새 배포 → 웹 앱 후 나온 주소입니다. /exec 로 끝나야 합니다.

확인 순서

  1. ① 배포 확인 — 주소가 살아 있는지 봅니다. KBSS 접수 엔드포인트 정상 동작 중 이 나오면 통과.
  2. ② 테스트 신청 보내기 — 신청폼과 똑같은 데이터를 실제로 보냅니다. 성공하면 시트에 「연결테스트」 행이 들어옵니다.
  3. 둘 다 통과하면 아래에 index.html에 넣을 줄이 만들어집니다. 복사해서 붙여넣으면 끝입니다.
  4. 시트에 들어간 테스트 행은 Apps Script의 테스트행삭제 함수로 지우거나 직접 삭제하세요.
